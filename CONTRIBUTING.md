# Contributing to Awesome AI Creator Stack

Thanks for helping. Every repo here has exactly one home, so a good suggestion says which job it does.

## A repo gets in when

1. Its repo is public, with a clear license.
2. It does a job that fits Awesome AI Creator Stack: Open-source AI tools and agent skills for creators: voice, video, motion, images, 3D, design, slides and writing.
3. It works today: maintained, or a finished classic that still runs.
4. You can say in one sentence why it matters.

## How to suggest one

Open an issue with the template **New pick**, or a pull request that adds one line in the right section:

```markdown
- **[name](https://github.com/owner/name)** · One sentence on the job it does.
```

Star counts are filled in by script, leave them out. No affiliate links, no self-promotion without disclosure, and nothing
that gets around a service's terms, its bot protection or a paywall.

## Removing a repo

If a project is dead, archived or changed its license, open an issue with the link. Removals are as welcome as additions.
